二手数据是Fong、Guo、Rao作者公开的真实5,050人牙膏实验记录。MATLAB实际计算原四臂组差，完成5,000轮参与者整簇重抽样；独立Python复算全部40项臂内指标、50项差值与相关计数。没有自创新的消费者、商品或行为数据集，原数据留本地，不上传标识及未经许可再分发的文件。

数据没有中文AI预算重审处理。新判准的责任依据由规范分析辩护，牙膏实验用于测量区分，预算措施的真人效果仍待直接研究。原合成模型及旧报告保留在历史目录，本版没有沿用其效应数字。

本版已修正论证复核提出的一处结论指代，明确经验结果不推出伦理义务。`parts/`为可编辑分段，`assemble_report.py`从真实CSV填入表格和数字，`build_report_docx.py`生成Word及逻辑图；最终导出PDF另行逐页核验。

交付版为17页、1,040,896字节，19项书目与正文引用对应，4表3图已逐页查看。作者元数据、常见个人路径和私密定位检查通过；详细记录见交付核对。正文约9,942个汉字。
