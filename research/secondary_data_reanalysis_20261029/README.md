## 来源与实际执行

数据来自Fong、Guo、Rao（2024），*Journal of Marketing Research* 61(4):659–681，DOI10.1177/00222437221147088。[作者Duke主页](https://people.duke.edu/~tg64/)提供Replication Files，已实际取得原ZIP并校验。主用牙膏信念子研究：5,050名美国Prolific参与者，每人10道选择题，合计50,500题、202,000条选项行。原作者设计题目，真实参与者选择；不是自然零售订单，也不是本文创建的数据集。

MATLAB R2023b已实际运行。保留普通/误导广告×控制/监管纠错四个真实处理臂，原人数为1,416、1,137、1,121、1,376。种子20261029，5,000次臂内参与者重抽样，保留同一人的10题。没有为同一人生成其他处理反应。

## 复现

1. 从作者主页进入复现目录，下载并解压原 `replication.zip`。
2. 将SHA256与来源记录比对；保留原件，不先重写或另制“消费者数据”。
3. 在基础MATLAB执行下例，输入原replication目录及独立输出目录：

```matlab
addpath('research/secondary_data_reanalysis_20261029/code')
run_secondary_data('原replication目录','独立输出目录')
```

程序只读取必要字段，检查匹配、每题四项恰选一项、每人十题、原价格菜单及信念范围。每人先形成统计向量，再整簇抽样；对本次比例和价格比率，这与抽取其十题全部记录等价。区间是逐项百分位区间，其他终点和比较为探索，不宣称全套95%同时覆盖。独立Python只核查点估计、差值和计数，未复跑抽样区间。

## 能回答的问题

数据支持原消息条件下信念、选择和标价的分别观察，不含充电器、中文AI多轮预算修订、关联提示、控制菜单、操作耗时或认知负担。因此本轮不估这些缺失变量，也不把原四臂改称R×C干预。预算责任由规范分析辩护，二手数据约束测量与验收。

原件包含参与者标识，且未找到明确再分发许可，保留本地。公开目录只有自行编写的分析代码、原件哈希和汇总统计；`bootstrap_aggregates.mat`保存重复抽样统计量而非参与者记录。旧合成结果保留为历史，不作为本轮经验依据。
