## 对补强稿的判断

补强稿可作为修改底稿。它把消费者决定地位、邀请依赖、已知具体用途及相称修复能力连接起来；合格更正示例、无须理解测验、未获授权前继续按当前预算执行、必要纠错与商业重开分开判断，都使责任规则更可审查。中国满减案例具体说明总支出与商品分摊价的区别，可保留为构造反例。

创新仍在纠错责任的对象、触发、完成与停止条件的细化。文字更完整不会自动形成新理论或新算法；强依赖跟踪及选择性再确认仍可能实现相同功能。国内实验证据也不能替代这项规范辩护。
