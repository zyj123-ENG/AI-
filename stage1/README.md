## 继承什么

- 成年消费者有支出和用途的初步决定权；购物协助具有可表达、可撤回的范围。
- 必要事实告知、探索比较、修改执行目标、交易授权分别判断。
- 必要纠错的理由不自动恢复已经拒绝的商业推动。
- 用户可以主动重开，也可以知情维持原决定；当前预算不被永久锁定。

## 当前新增哪一步

第一阶段从已表达的拒绝、预算与重开请求，讨论助手如何执行范围。当前研究进一步考察：**用户尚未撤回新目标，但AI已知道促成该目标修订的重要理由失去支持时，是否已有主动说明关联的责任？**

正文以后一问题为中心。前期成果用于概念基础、干预边界和反例，不照搬整篇报告，不将“拒绝后应停止”重复包装为新贡献。
