# Python–MATLAB v2 comparison

运行方式：MATLAB R2024b 桌面端执行 `run_paired_simulation_v2`；Python 使用冻结 v2 结果。两端使用同一配置、种子、48 单元和 N=1000，但 NumPy 与 MATLAB 的随机数实现不同，因此连续随机指标不要求逐项相等。

## 结果

- 单元数：Python 48，MATLAB 48；
- 离散机制指标：错误改写率、豁免后干预率、选择保留率、理由关联识别率和提示成本逐项一致；
- H4 退出成功率：A/B/C 均为 0，D 为 1，两端一致；
- 连续指标最大绝对差：目标偏离度约 0.171776，标准差约 0.073391；
- 综合损失最大绝对差：约 0.003483；
- 差异来源：MATLAB 与 NumPy 的随机数生成序列不同；
- 结论：机制分支、离散指标和输出结构一致，连续结果处于同一数量级。该比较不是逐随机数复现证明。

如需逐项数值完全一致，应先由 Python 导出固定的 `epsilon` 与 `rand_choice` 输入向量，再由 MATLAB 读取同一输入向量重跑。
