## 3. 策略综合表现与权衡（客观保守解释）

依据 48 单元模拟输出，**策略 D 并非在所有指标或所有情境下的绝对最优策略，而是提供了关键的条件性折中**：

### (1) 基准情境 (H1-B2) 最新实测数值严格同步
当前基准单元 ($H_1\text{-}B_2$) 下各策略实测指标如下（历史版本结果已废止，当前分析不使用旧版数值，统一以本表与 `strategy_comparison.csv` 为准）：
- **策略 D (本方案)**：目标偏离度 **17.7819** 元，综合损失 $W_1 = \mathbf{0.6414}$、$W_2 = \mathbf{0.6414}$、$W_3 = \mathbf{0.9271}$；
- **策略 A (弱基线)**：目标偏离度 34.1163 元，综合损失 $W_1 = 0.6823$、$W_2 = 0.6823$、$W_3 = 0.6823$；
- **策略 B (家长主义)**：目标偏离度 15.8837 元，综合损失 $W_1 = 0.4605$、$W_2 = 0.4605$、$W_3 = 0.6034$；
- **策略 C (繁琐基线)**：目标偏离度 7.8837 元，综合损失 $W_1 = 1.1577$、$W_2 = 1.1577$、$W_3 = 2.1577$。

**权衡解析**：
- 繁琐基线 C 的目标偏离度最低 ($7.88$ 元)，但产生了高达 $3.5$ 的交互提醒成本，综合损失受重罚；
- 家长主义基线 B 依靠直接改写使得偏离度降低，且其提醒成本仅 $0.5$，因而在 $W_1$ 纯等权损失下 ($0.4605$) 甚至低于策略 D ($0.6414$)；
- 策略 D 的核心价值在于**不预设写死结果，通过概率重选机制保留了用户的选择权**（选择保留率达 $1.0$），在偏离度（$17.7819$ 元）与适度成本（$1.0$）之间取得平衡。

### (2) 豁免情境 (H2/H3/H4) 与 H4 退出规则性质界定
- 在 $H_2$ (独立偏好) 与 $H_3$ (知情重申) 情境下，策略 D 识别豁免条件即刻停止，避免了策略 B 发生的 100% 错误改写（B 损失高达 $2.1429 \sim 4.1429$），也避免了策略 C 发生的 100% 豁免后强行追问（C 损失高达 $2.0000 \sim 3.0000$）；
- **H4 (明确退出) 规则性质与法律边界声明**：
  - **法律对应边界**：H4 用于检验明确退出请求下的停止干预规则；若涉及商业性推送，再与《消保法实施条例》第 24 条进行有限对应（第 24 条主要约束商业性信息与电话的发送、取消与停止，不可泛化为所有交互伦理规则）；

  - 验证审计中的 `INV_05`（退出响应规则）、`INV_08`（错误改写与豁免过干预识别）和 `INV_12`（状态机跳转语义）**均属于系统规则实现检查，旨在证明状态机严格按照预设逻辑运行，绝不证明真实商业 AI 平台或真人用户会在现实中以相同比例反应**。
