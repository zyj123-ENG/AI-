# 复现与构建说明

命令均从解压后材料根目录或仓库根目录执行，读取项目内文件。不要在原结果目录重跑统计覆盖固定输出。

## 1. 治理参考实现

Python 3.10以上、标准库即可：

```text
python governance/check_protocol.py
python governance/check_boundaries.py
```

写入governance/protocol_results.json，16项构造输入的工程断言。预算金额为整数分。该检查不生成真人反应、不测理解或自主性效果；同一依据版本一次邀请是可调整的实现默认值。

## 2. 原国内统计

原代码、CSV、LICENSE、字典与固定输出位于research/domestic_data_reanalysis_20261029。原作者来源与许可保留。MATLAB R2023b基础版，原主程序每个人群5,000轮，种子由程序固定。先创建单独输出目录，运行：

```matlab
addpath('research/domestic_data_reanalysis_20261029/code')
run_domestic_reanalysis('research/domestic_data_reanalysis_20261029/source/author_original/data/study4_memory_data.csv','reproduction_output')
```

Python独立点估计复核需numpy、pandas，显式输出到单独文件：

```text
python research/domestic_data_reanalysis_20261029/code/independent_validate.py --source research/domestic_data_reanalysis_20261029/source/author_original/data/study4_memory_data.csv --results research/domestic_data_reanalysis_20261029/results --output reproduction_validation.json
```

它复核点估计、频数、OLS与F/p，不独立重算bootstrap端点。本轮没有重新运行这项既有分析，固定结果来自原已执行记录；工程检查与原统计各自存档。

## 3. 文档构建与保护

Word包补丁：python governance/build_submission_report.py，需要lxml。基准文档在research/user_reinforced_domestic_revision_20261029。只修改新稿word/document.xml中的第四章及材料附录，保护摘要、前三章、结论和参考文献。此命令会重写新稿和revision_scope.json，请在副本中运行。PDF由LibreOffice渲染导出，分页需相同字体和排版环境；既有成品及哈希用于比较。

PPT源码为governance/build_defense.mjs，需要Node、Codex bundled @oai/artifact-tool及presentations技能辅助工具；Microsoft YaHei字体。设置TASK_WORKSPACE为包含目标仓库的构建工作目录（须是目标仓库的祖先目录或仓库本身），PRESENTATIONS_SKILL_DIR为本机技能目录，RUNTIME_PYTHON、RUNTIME_NODE和RUNTIME_NODE_MODULES指向本机运行时，随后node governance/build_defense.mjs <仓库绝对路径>。源码按RUNTIME_NODE_MODULES解析artifact-tool，不依赖临时node_modules链接。它会重新写入PPTX并渲染16页；源码中的环境依赖已明示，常规独立环境可直接使用成品PPTX，不宣称无环境依赖的一键构建。

完整仓库核对：python governance/verify_submission.py（另需lxml、pypdf）和python tools/verify_repository.py。匿名包不带完整文献历史或公开账号入口，使用自身SHA256SUMS.json核对全部条目；完整保护检查在公开仓库进行。

本轮环境版本：Python 3.12.14；lxml 6.1.1、pypdf 6.10.0、numpy 2.3.5、pandas 3.0.1。统计主分析原环境以results/run_metadata.json为准。没有随机治理输入；16项工程断言为确定性检查。

python governance/build_anonymous_package.py按明确清单重建ZIP。package_scope.json列明四个只用于匿名子集导航的说明页；这些页不冒充同名原件，原research文件保持原字节。其余包内文件与源码对应，SHA256SUMS.json覆盖除自身外的所有条目。
