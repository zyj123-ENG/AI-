# 文献资料的使用说明

原《文献目录与下载状态》记录本地获取情况；“已下载全文”不表示公开仓库镜像了所有全文。原件保留在用户本地，获取、阅读范围和版本记录不因入库改变。

已核验可再分发许可的全文随仓库保留。其余PDF用同名`.pdf.source.md`索引提供来源、原件SHA256与获取说明；完整书目、合法入口和方法分析见逐篇文献卡及research目录。研究助手可根据来源合法取得相同版本后继续核对。

第三方全文及图像的作者、期刊和许可仍归各自来源；本仓库没有为全部材料指定统一开源许可证。[许可记录](../provenance/third_party_licenses.json) · [公开范围](../provenance/PUBLICATION_SCOPE.md)

取得PDF、读摘要、读部分正文和精读正文分别记录，材料包本身不代表提交者本人已精读。
